# Student Marks and Grade Calculator

A beginner-friendly Python project that calculates student marks, percentage, and grades.

## Features
- Accepts a student's name
- Takes marks for four subjects
- Calculates total marks and percentage
- Assigns a grade based on percentage
- Validates marks between 0 and 100

## Technologies
- Python 3

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

   python main.py

## Concepts Practiced
- Variables and data types
- User input and type conversion
- Arithmetic operators
- Conditional statements
- Basic input validation
